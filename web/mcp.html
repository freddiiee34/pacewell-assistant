Les outils de Pacewell, directement dans Claude

Les outils de l'assistant sont aussi publiés en serveur MCP (Model Context Protocol), le standard ouvert qui permet à un assistant IA d'utiliser les outils d'une entreprise. Une fois branché, Claude peut chercher dans la documentation de Pacewell, consulter une commande ou ouvrir un retour depuis n'importe quelle conversation.

Adresse du serveur

https://assistant.simondelrue.fr/mcp

Le brancher

  1. Claude (web ou application) : Paramètres › Connecteurs › Ajouter un connecteur personnalisé, puis coller l'adresse ci-dessus.
  2. Claude Code : claude mcp add --transport http pacewell https://assistant.simondelrue.fr/mcp

Puis demander par exemple : « Où en est la commande PW104233 de camille.martin@exemple.fr, et peut-elle encore être retournée ? »

Outils exposés

OutilCe qu'il fait
chercher_documentationRecherche hybride (sens + mots) avec reclassement dans la documentation, extraits numérotés et sourcés.
consulter_commandeStatut, articles, suivi et date limite de retour. Exige le numéro et l'email de la commande.
ouvrir_retourVérifie les conditions et renvoie un récapitulatif, puis enregistre le retour une fois confirmé.

Serveur de démonstration : données fictives, nombre d'appels limité par un budget quotidien. Le même code sert l'assistant web et le serveur MCP : les vérifications (numéro + email, délais, confirmation) sont identiques.
